**Not run by us.** Written from Arize's docs, the `@arizeai/openinference-vercel` package (3.3.6) and Phoenix's
source on 2026-11-25.

## Set it up

Arize reads OpenInference attributes. `@arizeai/openinference-vercel` converts the AI SDK's spans to them; version 3 is
for `ai@7`, whose `gen_ai.*` spans this library emits by default. Install it and
`@opentelemetry/exporter-trace-otlp-proto`:

<include meta='title="lib/observability.ts"'>/_examples/observability/backends/arize.ts</include>

| | Arize AX | Phoenix |
|---|---|---|
| Endpoint | `https://otlp.arize.com/v1/traces` (EU: `https://otlp.eu-west-1a.arize.com/v1/traces`) | `http://<host>:6006/v1/traces` (the UI's port); Phoenix Cloud: the hostname in Settings |
| Auth | `arize-space-id` and `arize-api-key` headers | `Authorization: Bearer <PHOENIX_API_KEY>` |
| Protocol | Protobuf in every example; JSON not stated | **Protobuf only**: the server answers `415` to anything else |
| Project | resource attribute `openinference.project.name` | the same |

## Group a conversation

Both group sessions by `session.id`, which the example maps.
