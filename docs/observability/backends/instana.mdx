**Not run by us: no Instana tenant and no host agent.** Written from IBM's Instana docs on 2026-11-25. The generic
path it uses (`http/protobuf` with headers from the environment, resource attributes) was run against a local
Collector.

Instana is supported through the standard path: there is no Instana code, type or package in this library. Install
`@opentelemetry/exporter-trace-otlp-proto` and pick one of two modes.

## What to know

- **Protocol.** IBM's docs say "OTLP/gRPC or OTLP/HTTP" and every example uses gRPC or protobuf. They do not say
  whether OTLP JSON (this library's dependency-free default) is accepted, so this recipe sets `http/protobuf`. On an
  edge runtime where that package does not load, send to a Collector or to the host agent instead.
- **Endpoint forms.** The current SaaS table lists `https://otlp-http-<region>-saas.instana.io:443` (and
  `otlp-grpc-<region>-saas.instana.io:443`) for the regions blue, red, green, orange, coral, teal, mizu and pumpkin. The
  same page's examples also use `https://otlp-<region>-saas.instana.io:4318`. Self-hosted Instana uses
  `otlp-http.<base domain>` on 443. A `403` usually means a host for another region than your tenant's.
- **Identity.** Agentless data must be tied to an entity: the `x-instana-key` header (the agent key) plus a `host.id`,
  `faas.id` or `device.id` resource attribute, or else the `x-instana-host` header. IBM's page is not consistent on
  whether `host.name` also counts. On serverless hosts set one explicitly, as both examples do. IBM does not say what
  happens without one; data that is accepted but never shows up is the usual sign.
- **GenAI views.** Instana's GenAI observability is built on OpenLLMetry (Traceloop). It needs the resource attribute
  `INSTANA_PLUGIN=genai`, set in both examples, and reads `gen_ai.*` attributes (`gen_ai.operation.name`,
  `gen_ai.provider.name`, messages, tools). Keep the default `conventions: "genai"`. Whether every view fills from this
  library's spans could not be checked without a tenant; if one stays empty, map the attributes it needs in a Collector
  `transform` processor rather than in the app.
- **Browser spans** go through the relay like for any backend: the agent key never reaches the page. Instana's own
  website monitoring (EUM) is separate and can run beside it.
