## Set it up

Install `@braintrust/otel` (the OpenTelemetry code moved there from `braintrust` in 1.0) and pass its span processor
with the project:

`BraintrustSpanProcessor` reads `BRAINTRUST_API_KEY`, `BRAINTRUST_PARENT` and `BRAINTRUST_API_URL`. `parent` is
`project_name:<name>`, `project_id:<id>` or `experiment_id:<id>`.

### Without the package

<include meta='title=".env"'>/_examples/observability/env/braintrust-otlp.env</include>

Braintrust's docs do not state the protocol for traces; its own package sends JSON, which is what the built-in
exporter sends too.

The default `conventions: "genai"` fits: Braintrust maps `gen_ai.*` attributes to its inputs, outputs and metrics.
Braintrust documents no session or user attribute; `webmcp.conversation.id` is on every span to filter by.
