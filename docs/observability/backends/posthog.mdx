## Set it up

PostHog accepts OTLP over HTTP as JSON or protobuf, so the built-in exporter works with only the environment. Its path
does not end in `/v1/traces`: set the exact URL with the `…_TRACES_ENDPOINT` variable (the base variable would append
`/v1/traces` and get a `404`).

### With PostHog's exporter

Install `@posthog/ai` and pass its exporter. The option is `projectToken` (your `phc_` token); `host` defaults to
`https://us.i.posthog.com` (EU: `https://eu.i.posthog.com`).

<include meta='title="lib/observability.ts"'>/_examples/observability/backends/posthog.ts</include>

Either way, PostHog keeps only spans whose name or attributes start with `gen_ai.`, `llm.`, `ai.` or `traceloop.`.
This library's spans carry `gen_ai.*` attributes, so they pass. With the default `conventions: "genai"`, model spans
become `$ai_generation` events.

## Group a conversation

PostHog takes its session from `$ai_session_id`, or else from `gen_ai.conversation.id`, which the example maps. The
person is `posthog.distinct_id` (or `user.id`): set it from your own user id where you have one.
