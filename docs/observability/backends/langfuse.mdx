`LangfuseSpanProcessor` reads `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY` and `LANGFUSE_BASE_URL` (version 6 no longer
reads `LANGFUSE_HOST`). Regions: EU `https://cloud.langfuse.com`, US `https://us.cloud.langfuse.com`, Japan
`https://jp.cloud.langfuse.com`, HIPAA `https://hipaa.cloud.langfuse.com`, or your own host.

By default the processor exports only spans that carry a `gen_ai.*` attribute or come from a known instrumentation.
Every span of this library carries `gen_ai.operation.name`, so the run, tool and model spans pass.

### Without the package

Langfuse accepts OTLP over HTTP as JSON or protobuf (not gRPC), so the built-in JSON exporter works with only the
environment. The key is `base64("<public key>:<secret key>")`:

<include meta='title=".env"'>/_examples/observability/env/langfuse-otlp.env</include>

## Group a conversation

Langfuse groups traces into sessions by `langfuse.session.id` (or `session.id`), and people by `langfuse.user.id` (or
`user.id`). The example maps the conversation id to the session.
