## Group a conversation

Laminar groups traces into sessions by `lmnr.association.properties.session_id` on the root span (and people by
`…user_id`):

<include meta='title="lib/observability.ts"'>/_examples/observability/backends/laminar.ts</include>

Laminar reads `gen_ai.*` attributes, but its LLM views (and cost) need `lmnr.span.type` set to `LLM`, which this
library does not set. Traces arrive and show as a tree either way; to fill the LLM views, add the attribute to `chat`
spans in a Collector `transform` processor. We have not tried it.
