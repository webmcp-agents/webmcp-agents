Installation wires three pieces: the layer on the server, the relay route, and the observer on the page. Each has a
page of its own below, in the order you would reach for them, and each opens on the backend you picked during
installation wherever a backend changes something. Most apps never need more than the defaults; read on when you want
to change where spans go, what they record, or how many turns are kept.

## Where each one lives

- `@webmcp-agents/telemetry/server`: `defineObservability`, `otlp`, and the layer's `relay`, `event` and `span`.
  Server only.
- `@webmcp-agents/telemetry`: `observeAgents`, `consoleExporter`, `recordAgentEvent` and `withAgentSpan`, for the
  page.
- `@webmcp-agents/telemetry/react`: `<ObserveAgents>`, the same observer as a component.
- `@webmcp-agents/chat`: `onAgentRun`, the run events both sides are built on.
