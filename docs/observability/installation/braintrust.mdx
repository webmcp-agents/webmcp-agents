## Install the packages

The telemetry layer and its OpenTelemetry packages, plus Braintrust's span processor (the OpenTelemetry code moved to `@braintrust/otel` from `braintrust` in 1.0).

```package-install
npm install @webmcp-agents/telemetry @opentelemetry/api @opentelemetry/sdk-trace @ai-sdk/otel @braintrust/otel
```

## Add the relay route

The page's spans come to your own endpoint, so the backend's key never reaches the browser. The relay refuses other origins and requests with no `Origin` (a script, not a page); the `guard` is the per-IP limit for the rest. Keep its counts in a shared store in production, as for the chat ([Limits and budgets](/security/limits)).

## Check it in Braintrust

Start the app and send one message in the chat. Braintrust maps the `gen_ai.*` attributes to its inputs, outputs and metrics, so the default `conventions: "genai"` fits. It documents no session or user attribute: filter by `webmcp.conversation.id`, which every span carries.
