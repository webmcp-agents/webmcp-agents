<div class="install-steps">

## Install the packages

The telemetry layer and its OpenTelemetry packages. Laminar takes OTLP over HTTP, JSON or protobuf, on port 443, so the built-in exporter needs nothing more (gRPC, which Laminar recommends, is on port 8443).

```package-install
npm install @webmcp-agents/telemetry @opentelemetry/api @opentelemetry/sdk-trace @ai-sdk/otel
```

## Add the relay route

The page's spans come to your own endpoint, so the backend's key never reaches the browser. The relay refuses other origins and requests with no `Origin` (a script, not a page); the `guard` is the per-IP limit for the rest. Keep its counts in a shared store in production, as for the chat ([Limits and budgets](/security/limits)).

## Check it in Laminar

Start the app and send one message in the chat. The trace shows as a tree, grouped into a session by `lmnr.association.properties.session_id`.

:::note[Laminar's LLM views]
Laminar reads `gen_ai.*` attributes, but its LLM views (and cost) need `lmnr.span.type` set to `LLM`, which this library does not set. To fill them, add the attribute to `chat` spans in a Collector `transform` processor. We have not tried it.
:::
